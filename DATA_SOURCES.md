# Project data inventory

The project uses a bundled synthetic manager dataset, synthetic market fixtures for offline operation, and public market data retrieved on demand. It contains no real manager performance records or client portfolios. Public Yahoo Finance, FRED, and Kenneth French retrievals were successfully exercised during the initial build; the default demo continues to use explicitly labeled synthetic fixtures.

## Data used and its role

| Dataset or source | Contents | Use in the app | Delivery and provenance |
| --- | --- | --- | --- |
| Synthetic manager universe | 18 fictional managers; monthly returns, identity, strategy, redemption frequency, fees, and qualitative notes | Ingestion, validation, performance analytics, mandate eligibility, ranking, and the reproducible demo | Bundled [synthetic_managers.csv](data/synthetic_managers.csv); generated by [demo.py](backend/app/demo.py), seed 91 |
| Fresh upload demonstration | Three new fictional IDs with 180 monthly observations copied from the bundled Harbor, Vector and Orion histories; one duplicate and two invalid/conflicting rows | Demonstrate a first import and validation without reusing the already-loaded IDs | [demo_upload_fresh.csv](data/demo_upload_fresh.csv); 183 source rows. These are copied synthetic histories, not independent manager records or newly retrieved market data |
| Synthetic market fixtures | Seven benchmark return series, three macro/yield series, and six factor series | Offline benchmark comparisons, risk-free proxy, factor regressions, and regime analysis | Generated by `CachedDemoProvider` in [providers.py](backend/app/providers.py), seed 417; labeled cached and synthetic |
| Yahoo Finance through yfinance | Adjusted prices for SPY, QQQ, AGG, HYG, IWM, TLT, and GLD | Benchmark returns, beta, correlation, relative performance, and cross-benchmark comparisons | Retrieved when public data is refreshed; provider, retrieval time, identifier, and transformation retained |
| FRED | TB3MS, VIXCLS, and DGS10 | Monthly risk-free proxy and descriptive volatility/rate regimes | Public CSV retrieval; no separate FRED key required; per-series provenance retained |
| Kenneth French Data Library | Monthly Fama–French five factors plus momentum | Explanatory six-factor regressions and factor diversification score input | Two public ZIP/CSV downloads; percentages converted to decimal fractions; matched by month |
| User imports | CSV or XLSX manager observations supplied by the user | Extend the manager universe using the same validators and calculations | Original file bytes, original-source digest, worksheet, mapping, corrections, and source rows retained for reviewed imports |

Live sources are optional. Each failed provider falls back to its synthetic fixture with an explicit failure category. A refresh can produce mixed live and synthetic inputs; the app shows the combined status and individual source provenance. Synthetic fixtures are not stored copies of historical public observations.

The fresh-upload fixture uses `DEMOHEDGE`, `DEMONEUTRAL` and `DEMOTREND`. On the documented seeded universe, non-persisting preview accepted 180 observations, excluded the identical duplicate, and quarantined the invalid return and conflicting identity. Confirming this import adds three managers, so the fixed 18-manager presentation counts no longer apply. Preview and close without confirmation to preserve that walkthrough. Repeated confirmed imports are idempotent; Load demo retains uploads and does not remove these managers.

## Bundled synthetic manager dataset

The source file has **1,010 data rows**. A clean seed accepts **1,007 unique monthly observations** across **18 managers**. The three other rows comprise an identical duplicate, a conflicting identity under an existing identifier, and an invalid typo/return row. Normalization actions and warnings are recorded separately from rejected observations.

The standard history is October 2021 through September 2026. Exceptions intentionally exercise coverage checks and fail-closed eligibility:

All identities, performance, fees, redemption terms, and source notes in this file are fictional. Returns are generated from strategy mechanisms, synthetic factor exposure, Student-t noise, and explicit stress events. They are treated as reported net returns; management and performance fees are not deducted again. The histories are not empirically calibrated to an external manager dataset, and ranks or computed metrics are not hardcoded.

The deliberately messy file mixes percentage strings and decimal returns, date formats, capitalization, whitespace, strategy aliases, and fee representations. These cases test normalization, duplicate handling, identity conflicts, missing data, short histories, and source lineage.

## Public benchmark data

| Symbol | Benchmark proxy |
| --- | --- |
| SPY | US large-cap equities |
| QQQ | Nasdaq-100 equities |
| AGG | US aggregate bonds |
| HYG | US high-yield corporate bonds |
| IWM | US small-cap equities |
| TLT | Long-duration US Treasury bonds |
| GLD | Gold |

The Yahoo provider requests prices from September 2021 onward, with `auto_adjust=True`. It takes each completed calendar month’s final adjusted close and computes monthly price relatives. The current incomplete month is excluded. This is a dividend/split-adjusted ETF return approximation, not a licensed institutional total-return index. See the [yfinance download documentation](https://ranaroussi.github.io/yfinance/reference/api/yfinance.download.html).

## FRED macro and risk-free inputs

| Series | Source units | Transformation | App use |
| --- | --- | --- | --- |
| [TB3MS](https://fred.stlouisfed.org/series/TB3MS) | Annualized percentage yield, discount basis, for three-month Treasury bills | Divide by 100 and 12, or equivalently 1,200 | Monthly risk-free proxy for excess returns, Sharpe, Sortino, benchmark alpha, and factor regressions |
| [VIXCLS](https://fred.stlouisfed.org/series/VIXCLS) | Volatility index level | Monthly mean of available observations | Describe manager returns in months with mean VIX at least 25 |
| [DGS10](https://fred.stlouisfed.org/series/DGS10) | Ten-year Treasury yield in percent | Monthly mean, followed by month-to-month direction | Describe manager returns in rising/falling yield months |

TB3MS divided by 1,200 is an approximation, not an exact Treasury-bill holding-period return. Macro regimes describe historical associations; they are not forecasts or causal attribution. The live provider requests observations from September 2021 and excludes the current incomplete month.

## Kenneth French factor inputs

| Factor | Meaning |
| --- | --- |
| Mkt-RF | Market return less the library’s risk-free rate |
| SMB | Size factor |
| HML | Value factor |
| RMW | Profitability factor |
| CMA | Investment factor |
| Mom | Momentum factor |

Files retrieved: `F-F_Research_Data_5_Factors_2x3_CSV.zip` and `F-F_Momentum_Factor_CSV.zip`. Published monthly percentages become decimal fractions, missing-value sentinels are masked, and the files are joined on exact calendar months from October 2021 onward. Publication coverage may lag the most recent completed month.

Fund excess returns use the consistent FRED risk-free proxy. The French RF column is not substituted as the fund risk-free series; Mkt-RF remains the published factor definition. Regression uses at least 24 matched observations and a full-rank matrix. Explanatory residual alpha is an estimate, not evidence of repeatable skill. See the library’s [five-factor methodology](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library/f-f_5_factors_2x3.html) and [momentum methodology](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library/det_mom_factor.html).

## Derived and persisted project data

The backend derives performance/risk metrics, factor estimates, benchmark correlations, regime summaries, eligibility reasons, score contributions, and rankings from these inputs. Each evaluation snapshots its mandate, results, and evidence. These are computed records rather than independently sourced datasets.

PostgreSQL retains normalized observations, ingestion issues, market observations with lineage, evaluation evidence, and generated memo claims. Third-party observations are fetched at runtime and stored locally; historical public datasets and local database volumes are not bundled in Git. Excel and Word exports are static snapshots of saved evaluations, not new source data.

OpenAI and local Ollama are optional interpretation providers, not financial data sources. They receive selected verified evidence and untrusted source notes; software retains ownership of calculations, eligibility, and rankings. In local mode, Qwen 2.5 runs on the host machine and no memo context is sent to OpenAI. The provider/model used is recorded with each generated artifact.

## Sources not used

No EDHEC or Kaggle manager dataset is incorporated or redistributed. There are no Bloomberg or Aladdin feeds, licensed institutional datasets, real manager factsheets, holdings, client portfolio allocations, or production account records. References to possible future integrations do not imply that those sources supplied project data.
